# FitTime

Учебный Django-проект для онлайн-записи клиентов фитнес-клуба на тренировки.

## Что есть в проекте

- регистрация клиента с проверкой логина, пароля, имени, телефона и email;
- авторизация и выход;
- страница с доступными тренировками;
- оформление записи на будущую дату и время;
- личный кабинет клиента со списком записей;
- панель администратора для пользователя `Admin` с паролем `FitTimeAdmin`;
- изменение статуса записи: новая, подтверждена, клиент посетил тренировку, тренировка проведена, отменена;
- модели базы данных для клиентов, тренировок, записей и отзывов;
- ER-диаграмма в файле `docs/er_diagram.md`.

## Запуск

```bash
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

После миграций автоматически создаются тестовые тренировки и администратор:

- логин: `Admin`
- пароль: `FitTimeAdmin`

## Основные страницы

- `/` — главная страница со слайдером;
- `/register/` — регистрация;
- `/login/` — авторизация;
- `/workouts/` — выбор тренировок;
- `/appointment/` — оформление записи;
- `/cabinet/` — личный кабинет;
- `/admin-panel/` — панель администратора.
